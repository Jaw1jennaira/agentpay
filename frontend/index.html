Cara demo (end-to-end, testnet)

  1. Connect MetaMask di BSC Testnet (chain 97) dengan tBNB dari faucet.
  2. Merchant (pemegang Agent ID): tab Buat Invoice — isi nama .ai, jumlah, token, memo → buat invoice, catat ID-nya.
  3. Customer: tab Bayar — cek nama .ai merchant, muat invoice berdasarkan ID, Approve (bila MockUSDT), lalu Bayar. Cek link tx di BscScan testnet.
  4. Tip: tab Tip — kirim tBNB ke nama .ai mana pun beserta memo.
  5. Dashboard: merchant melihat invoice-nya berubah jadi Dibayar beserta payer.

Non-custodial: dana tidak pernah lewat server kami — semua pembayaran langsung antar wallet lewat kontrak AgentPay. Jangan pernah membagikan private key / seed phrase ke siapa pun.
